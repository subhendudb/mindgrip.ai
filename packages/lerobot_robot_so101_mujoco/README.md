# LeRobot robot plugin

Installable package `lerobot_robot_so101_mujoco` — discovered automatically by
`register_third_party_plugins()` when present in the environment.

```bash
pip install -e .
# then:
lerobot-teleoperate --robot.type=so101_mujoco ...
mjpython -m lerobot_robot_so101_mujoco.run_viewer   # macOS viewer
```
