Wrapper

How to run

From the repo root. Config is saved in .so101_cli.env. Defaults: LEADER_ID / FOLLOWER_ID = LeoArm · HF_LEROBOT_HOME = ~/Documents/lerobot (not ~/.cache). Example ports on this Mac setup: leader /dev/tty.usbmodem5AE60832361 · follower /dev/tty.usbmodem5B141118901 — rediscover with option 0 if they change. 

./so101_cli_menu.sh
./so101_cli_menu.sh 5          # one-shot (calibrate leader)
DRY_RUN=1 ./so101_cli_menu.sh 8
⚠️
Task string: the menu uses $TASK from .so101_cli.env. Script default is still Pick coloured block and place in matching bin. For MindGrip binary sort, set TASK via option C to: Pick object: put match box in match-box bin; put other objects in reject bin

0 Find USB ports

Menu: lerobot-find-port. Run after plugging / unplugging a bus. Unplug the adapter you want to identify when prompted.

uv run lerobot-find-port
1 Find cameras (OpenCV)

Menu: lerobot-find-cameras opencv. Note the index for CAM_INDEX (option C).

uv run lerobot-find-cameras opencv
2 Install / sync deps

feetech + viz + hardware + dataset. Open Step 1 in roadmap →

uv sync --locked --extra feetech --extra viz --extra hardware --extra dataset
uv run python --version
3 Program motor ID

Connect only the target motor. Prompts for leader/follower port and ID 1–6. Open Step 2 →

# Leader example (discover port with option 0)
uv run python set_middle_positions.py --port /dev/tty.usbmodem5AE60832361 --id 1

# Follower example
uv run python set_middle_positions.py --port /dev/tty.usbmodem5B141118901 --id 1
4 Setup motors

Official helper — choose leader (so101_leader) or follower (so101_follower). Open Step 2 →

uv run lerobot-setup-motors \
  --teleop.type=so101_leader \
  --teleop.port=/dev/tty.usbmodem5AE60832361

uv run lerobot-setup-motors \
  --robot.type=so101_follower \
  --robot.port=/dev/tty.usbmodem5B141118901
5 Calibrate leader

Writes calibration under $HF_LEROBOT_HOME/calibration/teleoperators/so_leader/LeoArm.json (default home ~/Documents/lerobot). Prefer LeLab on a laptop when available — LeLab guide. Open Step 4 →

uv run lerobot-calibrate \
  --teleop.type=so101_leader \
  --teleop.port=/dev/tty.usbmodem5AE60832361 \
  --teleop.id=LeoArm
6 Calibrate follower

Writes $HF_LEROBOT_HOME/calibration/robots/so_follower/LeoArm.json. Same id LeoArm for both arms on this project. Open Step 4 →

uv run lerobot-calibrate \
  --robot.type=so101_follower \
  --robot.port=/dev/tty.usbmodem5B141118901 \
  --robot.id=LeoArm
7 Teleop (no camera)

Confirm leader → follower mirroring before recording. Open Step 5 →

uv run lerobot-teleoperate \
  --robot.type=so101_follower \
  --robot.port=/dev/tty.usbmodem5B141118901 \
  --robot.id=LeoArm \
  --teleop.type=so101_leader \
  --teleop.port=/dev/tty.usbmodem5AE60832361 \
  --teleop.id=LeoArm
8 Teleop (USB camera + Rerun)

Adds --robot.cameras and --display_data (installs viz / rerun if needed). Sync issues? Troubleshooting → Open Step 5 →

uv run lerobot-teleoperate \
  --robot.type=so101_follower \
  --robot.port=/dev/tty.usbmodem5B141118901 \
  --robot.id=LeoArm \
  --teleop.type=so101_leader \
  --teleop.port=/dev/tty.usbmodem5AE60832361 \
  --teleop.id=LeoArm \
  --robot.cameras="{front: {type: opencv, index_or_path: 0, width: 640, height: 480, fps: 30, fourcc: MJPG}}" \
  --display_data=true
9 Teleop sync help (Roadmap)

Opens Roadmap · Troubleshooting (hardware, calibration, lag / offset / per-joint sync tips). Same as menu option 9.

10 Record demos (USB camera)

Uses $TASK, camera JSON, episode count / times from config. Prefer MindGrip binary-sort task string (option C). Open Step 7 →

uv run lerobot-record \
  --robot.type=so101_follower \
  --robot.port=/dev/tty.usbmodem5B141118901 \
  --robot.id=LeoArm \
  --teleop.type=so101_leader \
  --teleop.port=/dev/tty.usbmodem5AE60832361 \
  --teleop.id=LeoArm \
  --robot.cameras="{front: {type: opencv, index_or_path: 0, width: 640, height: 480, fps: 30, fourcc: MJPG}}" \
  --dataset.repo_id=${HF_USER}/pick_place_sorting \
  --dataset.num_episodes=100 \
  --dataset.episode_time_s=120 \
  --dataset.reset_time_s=60 \
  --dataset.single_task="$TASK" \
  --display_data=true
11 Visualize dataset

lerobot-dataset-viz — resolves stamped repo ids under $HF_LEROBOT_HOME. Prompt for episode index or all.

uv run lerobot-dataset-viz \
  --repo-id ${HF_USER}/pick_place_sorting \
  --video-backend pyav \
  --num-workers 0 \
  --all-episodes
# Or: --episode-index N · add --root /path/to/local/dataset when present
12 Train ACT (cloud CUDA)

Run on a CUDA GPU host — not on a typical laptop/desktop or Pi. Prefer ACT for this project. Open Step 8 →

uv run lerobot-train \
  --policy.type=act \
  --dataset.repo_id=${HF_USER}/pick_place_sorting \
  --output_dir=outputs/train/sorting_act \
  --job_name=sorting_act \
  --policy.device=cuda
13 Train Diffusion (cloud CUDA)

Alternate policy — also requires CUDA. Open Step 8 →

uv run lerobot-train \
  --policy.type=diffusion \
  --dataset.repo_id=${HF_USER}/pick_place_sorting \
  --output_dir=outputs/train/sorting_diffusion \
  --policy.device=cuda
14 Rollout / evaluate

Copy checkpoint to the host laptop/desktop or Pi (or use a Hub path), then roll out. Open Step 9 →

uv run lerobot-rollout \
  --robot.type=so101_follower \
  --robot.port=/dev/tty.usbmodem5B141118901 \
  --robot.id=LeoArm \
  --robot.cameras="{front: {type: opencv, index_or_path: 0, width: 640, height: 480, fps: 30, fourcc: MJPG}}" \
  --policy.path=outputs/train/sorting_act/checkpoints/last \
  --dataset.repo_id=${HF_USER}/eval_pick_place_sorting \
  --dataset.num_episodes=20 \
  --dataset.single_task="$TASK" \
  --strategy.num_episodes=20 \
  --display_data=true
15 Replay episode on follower

Open-loop replay — camera not required. Stop LeLab teleop/record first so the follower USB is free. Clear the table or reset objects to the episode start. Needs a local dataset under $HF_LEROBOT_HOME.

uv run lerobot-replay \
  --robot.type=so101_follower \
  --robot.port=/dev/tty.usbmodem5B141118901 \
  --robot.id=LeoArm \
  --dataset.repo_id=${HF_USER}/pick_place_sorting \
  --dataset.root=$HF_LEROBOT_HOME/${HF_USER}/pick_place_sorting \
  --dataset.episode=0
16 MuJoCo interactive viewer

Native Control sliders drive the sim arm (no keyboard teleop). On macOS prefers mjpython. MuJoCo docs →

# macOS with mjpython in .venv
mjpython -m lerobot_robot_so101_mujoco.run_viewer

# Fallback
uv run python -m lerobot_robot_so101_mujoco.run_viewer
17 MuJoCo — real leader → sim

Physical leader drives the sim arm (so101_mujoco + so101_leader, --robot.show_viewer=true). MuJoCo docs →

# On macOS may use mjpython -m lerobot.scripts.lerobot_teleoperate …
uv run lerobot-teleoperate \
  --robot.type=so101_mujoco \
  --robot.id=sim_follower \
  --robot.show_viewer=true \
  --teleop.type=so101_leader \
  --teleop.port=/dev/tty.usbmodem5AE60832361 \
  --teleop.id=LeoArm \
  --display_data=false
18 Install MuJoCo extra

Ensures so101-lab plugins (editable installs) + viz + feetech so leader→sim still works.

uv pip install -e packages/lerobot_teleoperator_so101_keyboard

uv sync --extra viz --extra feetech

Runs ./start.sh from the repo root (docs web UI).

21 Record demos (no camera) — Use Case 1

Fixed pick & place — state + action only. Sets --dataset.push_to_hub=false and --display_data=false. Still uses $TASK from config.

uv run lerobot-record \
  --robot.type=so101_follower \
  --robot.port=/dev/tty.usbmodem5B141118901 \
  --robot.id=LeoArm \
  --teleop.type=so101_leader \
  --teleop.port=/dev/tty.usbmodem5AE60832361 \
  --teleop.id=LeoArm \
  --dataset.repo_id=${HF_USER}/pick_place_sorting \
  --dataset.num_episodes=100 \
  --dataset.episode_time_s=120 \
  --dataset.reset_time_s=60 \
  --dataset.single_task="$TASK" \
  --dataset.push_to_hub=false \
  --display_data=false
C Configure ports / ids / HF / camera

Interactive prompts for LEADER_PORT, FOLLOWER_PORT, ids, HF_USER, DATASET_REPO, EVAL_REPO, TASK, camera index, policy path, episode counts / times — then writes .so101_cli.env.

Recommend setting TASK to the MindGrip binary-sort string (see notice above).

D Toggle dry-run

Print commands only — does not execute. Same as DRY_RUN=1 for one-shot runs.

DRY_RUN=1 ./so101_cli_menu.sh 8
S Save config now

Writes current in-memory settings to .so101_cli.env without re-prompting.

Q Quit

Exit the interactive menu.
