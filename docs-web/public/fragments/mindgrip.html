MindGrip AI

A project lab on top of LeRobot — teach any similar arm to sort, pick, and place.

MindGrip AI is the curriculum and tooling layer for cognitive targeting and handling: assemble → calibrate → teleop → record → train ACT → deploy. This repo keeps vanilla LeRobot / LeLab intact and adds the pieces a real lab needs.

Purpose of this repository

What so101-lab is for

Upstream LeRobot is the engine. This overlay is the lab workbook: plugins, a guided CLI, optional UX patches, and end-to-end docs so you can finish a sorting robot — and reuse the same pattern on other LeRobot-class arms.

Primary lab (this kit)

Binary sorter on SO-101 (leader + follower): match-box → match-box bin; everything else → reject. Learned with ACT from teleop demos — not hand-coded trajectories.

Reusable for similar arms

Same loop works for other Feetech / LeRobot-style kits: ports, calibration ids, camera name, task string, dataset → train → rollout. Swap hardware config; keep the curriculum and CLI shape.

Overlay, not a fork

Vanilla lerobot/ stays upstream-clean. Plugins install as lerobot_robot_* / lerobot_teleoperator_* packages; optional patches are explicit and reversible.

Two paths, one project

Prefer LeLab on a laptop for calibrate → record → HF Jobs → deploy. Use so101_cli_menu.sh on Pi, for motor IDs, debugging, and scripting.

Hardware→ Calibrate→ Teleop→ Record→ Train ACT→ Rollout

Why this repo

LeRobot and LeLab are excellent foundations. This lab fills the gaps between “library docs” and “a finished sorter on your desk.”
