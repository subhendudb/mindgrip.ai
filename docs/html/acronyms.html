Platforms, tools & products

Acronym Stands for / full name In this project
HF Hugging Face Company / platform hosting models, datasets, and HF Jobs (cloud GPUs).
Hub Hugging Face Hub Online library where you push datasets and download/share policies.
HF Jobs Hugging Face Jobs Managed cloud GPU training jobs — preferred for Step 8 on MacBook Air.
LeRobot LeRobot (Hugging Face robotics library) Framework for teleop, datasets, training, and robot rollout.
LeLab LeRobot Lab (GUI) Recommended graphical app for calibrate → teleop → record → train → deploy.
CLI Command-Line Interface Terminal commands (lerobot-train, uv run …) instead of the GUI.
GUI Graphical User Interface Point-and-click app (LeLab) instead of typing long flags.
uv uv (Astral package manager) Installs Python deps and runs tools; this Mac uses Python 3.13.4 via uv.
OS Operating System macOS on this host; Linux notes appear for other machines.
PC Personal Computer The MacBook Air control computer in this setup.
UI User Interface Screens and controls in LeLab or Rerun.
API Application Programming Interface Code-facing camera / robot interfaces (e.g. OpenCV camera config).
YAML YAML Ain’t Markup Language Config / job description format (HF Jobs can avoid hand-writing this via LeLab).
JSON JavaScript Object Notation File format for calibration (this project: LeoArm.json under so_leader/ and so_follower/; legacy examples often use my_leader.json / my_follower.json).
MJPG Motion JPEG Camera codec often more stable over USB (fourcc: MJPG).

Hardware & robotics

Acronym Stands for / full name In this project
SO-101 / SO-ARM101 Standard Open Arm 101 (desktop arm kit) The leader + follower arms used for teleop and sorting.
SO-100 Standard Open Arm 100 Earlier related arm family; docs may mention it next to SO-101.
DOF Degrees Of Freedom SO-101 is 6-DOF (six joints including gripper).
STS3215 Feetech STS3215 servo Smart servo motor model on the arms (variants C001 / C018 / C046).
TTL Transistor–Transistor Logic (serial bus) Bus used by Feetech motors at ~1 Mbps.
USB Universal Serial Bus Arm adapters (/dev/tty.usbmodem…) and the overview webcam.
PSU Power Supply Unit External 5 V (leader) and 12 V (follower) supplies — required (USB alone is not enough).
ID Identifier Motor bus ID (1–6 per arm) and robot/teleop ids (this project: both LeoArm; legacy docs may show my_leader / my_follower).
J1–J6 Joint 1 through Joint 6 Joint nicknames: pan, lift, elbow, wrist flex, wrist roll, gripper.
EE End-Effector Tip of the arm (gripper) that picks objects.
FK Forward Kinematics Compute gripper pose from joint angles (URDF helper use). Full SO-101 derivation: SO-101 Forward & Inverse Kinematics.
IK Inverse Kinematics Compute joint angles from a desired gripper pose (ROS2 / planning paths). Same page walks the Jacobian solver used for EE / planning paths.
URDF Unified Robot Description Format Robot model file for viz / kinematics — optional helper, not required for LeRobot IL.
ROS2 Robot Operating System 2 Optional robotics middleware; not required for this sorting pipeline.
RViz ROS Visualization Optional 3D viewer in the ROS ecosystem.

Learning, policies & ML

Acronym Stands for / full name In this project
IL Imitation Learning Learn from human demos (teleop) instead of hand-coded pick scripts.
BC Behaviour Cloning Classic imitation style: map observations → actions from demos.
ML Machine Learning Training the neural policy in Step 8.
Policy Control policy (neural network) Model that maps camera + joints → motor commands.
ACT Action Chunking Transformer Recommended first policy for pick-and-place sorting.
Diffusion / Diffusion Policy Denoising diffusion policy Smoother multi-modal actions; heavier than ACT on this Air.
VLA Vision–Language–Action model Policies that take images + language (e.g. SmolVLA, Pi-0 family).
SmolVLA Small Vision–Language–Action model Advanced LeRobot VLA; not practical to train on M1 Air 8 GB.
Pi-0 / π₀ / Pi0 Physical Intelligence π₀ policy Large flow-matching VLA; cloud / big GPU only.
Pi0Fast / π₀-FAST Pi-0 Fast variant Faster tokenization variant of Pi-0; still compute-heavy.
Pi05 / π₀.₅ Pi-0.5 policy Later Pi-family model; not for local Air training.
DiT Diffusion Transformer Architecture used in some multitask policies.
RL Reinforcement Learning Learn from reward/trial-and-error; separate from this IL sorting path.
HIL Human-In-the-Loop Human stays involved during data/RL collection (related tutorials).
PEFT Parameter-Efficient Fine-Tuning Train fewer weights (e.g. LoRA) — advanced training option.
LoRA Low-Rank Adaptation Popular PEFT method for fine-tuning large models.
OOM Out Of Memory Crash risk when training large policies on 8 GB unified memory.
VRAM Video RAM (GPU memory) On NVIDIA cards; on Apple Silicon, memory is unified with system RAM.

Compute (MacBook Air host)

Acronym Stands for / full name In this project
CPU Central Processing Unit M1 has 8 CPU cores; handles teleop, recording, light inference.
GPU Graphics Processing Unit M1 has a 7-core GPU; useful for viz/inference, weak for full training.
MPS Metal Performance Shaders Apple Silicon PyTorch accelerator backend (alternative to CUDA).
CUDA Compute Unified Device Architecture NVIDIA GPU API — used on cloud HF Jobs, not on MacBook Air.
SSD Solid-State Drive Internal disk; keep free space for demos and checkpoints.
GB Gigabyte Memory/disk size (this Air: 8 GB RAM).
