SO-101 MuJoCo simulation

Use a MuJoCo-simulated SO-101 follower with LeRobot teleoperate / record.

The default scene (src/lerobot/robots/so101_mujoco/assets/so101_scene.xml) is the official TheRobotStudio SO-ARM100 MuJoCo model (Simulation/SO101, so101_new_calib). IITD_EPR_KIT4-main only ships the same CAD as ROS2 URDF/Gazebo (no MJCF); use that kit for RViz/Gazebo, and this scene for MuJoCo.

Mode Follower Teleop Use when
A — Leader connected --robot.type=so101_mujoco --teleop.type=so101_leader Real leader plugged in; practice / record without moving the real follower
B — Sim only --robot.type=so101_mujoco --teleop.type=so101_keyboard No arms; generate datasets and debug the ML pipeline

Install: uv sync --extra so101-mujoco (add --extra feetech for a real leader).

Full commands and keyboard map: examples/so101_mujoco/README.md (local path examples/so101_mujoco/README.md).

Quick starts

# B — keyboard + sim (no hardware)
uv run lerobot-teleoperate \
  --robot.type=so101_mujoco --robot.id=sim_follower \
  --teleop.type=so101_keyboard --display_data=true

# A — real leader → sim follower
uv run lerobot-teleoperate \
  --robot.type=so101_mujoco --robot.id=sim_follower \
  --teleop.type=so101_leader --teleop.port=/dev/tty.usbmodemXXXX --teleop.id=LeoArm \
  --display_data=true
# Record sim dataset for ACT / other policies
uv run lerobot-record \
  --robot.type=so101_mujoco --robot.id=sim_follower \
  --teleop.type=so101_keyboard \
  --dataset.repo_id=${HF_USER}/so101_mujoco_demo \
  --dataset.num_episodes=10 \
  --dataset.single_task="Pick and place in sim" \
  --display_data=true

Sim demos are for learning the pipeline. For the physical pick-and-place sorter, still collect real USB-cam demos on the follower (see project page).

Link lengths and joint limits from this model are the numbers used in SO-101 Forward & Inverse Kinematics.
